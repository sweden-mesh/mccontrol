Commands that take something away

These are sent only after you have been told what they do and have
pressed [ Send anyway ]:

  region denyf *       stops the repeater forwarding every unscoped
                       message. It may be the only link between two
                       places that rely on that.
  region denyf <name>  stops forwarding that scope.
  region remove <name> deletes the region; messages scoped to it drop.
  set autoreply off    stops answering test requests.
  set repeat off       stops forwarding anything at all.
  set mqtt.cmd off     switches the control plane off; the next command
                       must come over serial.
  erase                erases the node.

A broadcast of one of these cannot be undone in one step. The node does
not second-guess a signed command; this dialog is where the question is
asked. See [[send]].
