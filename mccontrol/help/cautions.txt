Commands that take something away

These are sent only after you have been told what they do and have
pressed [ Send anyway ]:

  region denyf *       stops the repeater forwarding every unscoped
                       message. It may be the only link between two
                       places that rely on that.
  region denyf <name>  stops forwarding that scope.
  region remove <name> deletes the region; messages scoped to it drop.
  set autoreply off    stops answering test requests.
  reboot, clkreboot    restarts the node: off the air and off the control
                       plane until it is back.
  set mqtt.iata        moves the node to another region's topics; change
                       its region here to match.
  set mqtt.presets     changes how many MQTT slots run.
  set mqttN.*          changes that slot's broker or credentials; if the
                       control plane rides that slot, it may go silent.
  set name             renames the node as the whole mesh sees it.

set repeat off, erase and set mqtt.cmd* are not cautions any more: the
firmware refuses them outright, and so does this tool, before signing
(see [[commands]]).

A broadcast of one of these cannot be undone in one step. The node does
not second-guess a signed command; this dialog is where the question is
asked. See [[send]].
