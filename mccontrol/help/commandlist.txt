The command list

Every command the control plane admits, by group: reads, auto-reply,
regions, tuning, MQTT, node, for the tagged devices, or the current one
when none is tagged. Typing narrows the list.

What choosing a command does depends on what it needs:

  nothing       it runs at once, and the reply is shown when it arrives
                (ver, region, reboot)
  one value     one of its choices is picked, then it runs
                (set autoreply on|off, set autoreply.mode ...)
  several       several of its choices are picked
  free text     a value is typed, with examples beside it (region put
                se-jkp *, set txdelay 0.5); an empty value asks again

Grey entries are commands the device's firmware does not admit: they
cannot be chosen, and the list says how many there are, what the device
reports (ar-10, or "unknown", which counts as the oldest) and that
reading names and versions fills it in. The fleet runs several firmware
versions for months, so this is how a command slot is never spent on a
not-allowed. ar-10, the build in the field, admits the auto-reply
settings, the two triggers and a dozen reads; ar-11 admits everything
on the deny list's far side (ver, get name, get stats, the region map,
the tuning writes, reboot...). To make the grey go away, flash.

A command that takes something away still asks first (see [[cautions]]),
and one the firmware would refuse is stopped before it is signed, with
the reason (see [[commands]]).

The full table, with each command's kind, is "mccontrol commands".

See [[send]], [[reads]] and [[keys]].
