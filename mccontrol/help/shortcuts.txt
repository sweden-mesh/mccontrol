Shortcuts: nine commands on a key each

A command per slot, sent to the tagged devices (or the current one)
without asking for the command. The result is shown and kept in history
exactly as a sent command is, and a command that takes something away
still asks first.

The slots as shipped:

  1  region          4  get autoreply
  2  ver             5  get radio
  3  get name        6  get repeat

Where the nine slots are edited, and the key each is on, in your
interface is in [[keys]]. On the command line the same slots are

  mccontrol shortcuts                 list them
  mccontrol shortcuts --set 7 "get flood.max"
  mccontrol alt 2 loutest             send slot 2's command to loutest
  mccontrol alt 1 JKG --all           to every node in a region

See [[send]], [[keys]] and [[commands]].
