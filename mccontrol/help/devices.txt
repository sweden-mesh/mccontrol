Devices

A device is a repeater you manage: a name you choose, its node id (the
first eight hex characters of its public key, which is how the firmware
names it on the control topics), the region its observers use (the IATA
code, such as JKG), and notes.

F4 edits the cursor device. F8 forgets it after a confirmation; its
history file stays on disk. Devices are added by [[discover]] or by hand
on the command line (see [[cli]]).

A device with no region cannot be sent to; set one with F4. A region
belongs to the device, not to the program: you may run repeaters in
several.

Names and versions from the fleet. "n" (Devices > Names and versions)
sends "get name" and "ver" to the tagged devices, or the cursor one: a
device you have not named takes the name the node answers with, a name
you gave is kept, and every device stores its firmware version, shown
short in the Ver column (1.17.1-ar-10) and sortable. Two signed reads
per device, each one of the node's command slots this hour; more than
three devices asks first. Firmware that admits neither read answers
not-allowed and the device keeps what it had. "mccontrol refresh" does
the same from the command line.
