Shortcuts: Alt+1 to Alt+9

A command per key, sent to the tagged devices (or the one under the
cursor) without the Send dialog. The result lands in the right panel and
in history exactly as a sent command does, and a command that takes
something away still asks first.

The slots as shipped:

  Alt+1  region          Alt+4  get autoreply
  Alt+2  ver             Alt+5  get radio
  Alt+3  get name        Alt+6  get repeat

Options > Shortcuts edits the nine slots; the Send menu lists the ones
that are set, with their keys. On the command line the same slots are

  mccontrol shortcuts                 list them
  mccontrol shortcuts --set 7 "get flood.max"
  mccontrol alt 2 loutest             send Alt+2's command to loutest
  mccontrol alt 1 JKG --all           to every node in a region

A terminal sends Alt+digit as Escape followed by the digit; a few send
nothing for it, and then the Send menu (Alt+S, or F9) reaches the same
commands.

See [[send]], [[keys]] and [[commands]].
