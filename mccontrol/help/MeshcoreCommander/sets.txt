Command sets

A set is a named list of commands sent in order to one device, the
tagged ones, or every node in a region. Each step waits for its answer;
a refusal or silence stops the rest, so a rollout never half-applies.
Every step is recorded in history like a sent command.

The set shipped as the example, add-scope:

  1. region put {arg} *
  2. region allowf {arg}
  3. region save
  4. region

"{arg}" is asked for when the set runs (here the scope's name, such as
se-jkp). Send > Command set runs one; Options > Command sets defines,
changes or removes one, six steps at most. On the command line:

  mccontrol sets                                   list them
  mccontrol sets --set reads ver "get name"        define one
  mccontrol sets --remove reads
  mccontrol run add-scope loutest se-jkp           run one
  mccontrol run add-scope JKG se-jkp --all         on every node in JKG

A step that takes something away (see [[cautions]]) is confirmed before
the set starts, not in the middle of it.

See [[send]], [[shortcuts]] and [[commands]].
